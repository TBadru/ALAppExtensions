# Business Central extensibility requests (retired)

> [!IMPORTANT]
> **This repository was retired on 19 October 2026.**
>
> - **New issues and pull requests are no longer accepted here.** Business Central application contributions and extensibility requests, including event requests, now belong in [BCApps](https://github.com/microsoft/BCApps).
> - **The final backlog has been closed.** Accepted work still in progress continues through its existing internal tracking or BCApps pull request. Retirement does not cancel that work.
> - This repository is retained for historical reference. Existing code, issues, comments, and links remain available.
>
> See [the retirement announcement](https://github.com/microsoft/ALAppExtensions/issues/30411) for details. Thank you to everyone who contributed to ALAppExtensions.

This repository no longer accepts new issues or pull requests.

For Business Central application contributions and extensibility requests, use the [BCApps](https://github.com/microsoft/BCApps) repository.

## Create an extensibility request

Create an [extensibility request in BCApps](https://github.com/microsoft/BCApps/issues/new/choose) when you need Microsoft to make the application easier to extend, for example:

- Add a new integration event.
- Change function visibility, for example by making a function external.
- Replace an option with an extensible enum.
- Make another extensibility enhancement that helps unblock your app.

Before creating a request, search existing issues to avoid duplicates and read the guidance for [creating extensibility requests](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/developer/create-extensibility-request).

## Other requests

- **Code contributions and pull requests:** Use [BCApps](https://github.com/microsoft/BCApps).
- **Extensibility requests:** Use [BCApps](https://github.com/microsoft/BCApps/issues/new/choose).
- **Product ideas:** Use [BC Ideas](https://aka.ms/bcideas).
- **Product defects or customer-impacting issues:** Use [Business Central support](https://aka.ms/bcsupport).

Issues in this repository do not fall under SLAs (Service Level Agreements), have no guaranteed time to mitigation, and provided fixes are not guaranteed to be backported to all supported versions of the product.
